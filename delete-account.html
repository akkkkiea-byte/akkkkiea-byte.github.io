계정 및 데이터 삭제 안내

Moodie · 최종 수정일: 2026년 8월 26일

Moodie 이용자는 언제든지 계정과 계정에 연결된 모든 데이터를 삭제할 수 있습니다. 아래 두 가지 방법 중 편한 쪽을 이용해 주세요.

방법 1. 앱에서 직접 삭제하기

  1. Moodie 앱을 실행하고 로그인합니다.
  2. 하단 메뉴에서 프로필 탭으로 이동합니다.
  3. 회원탈퇴를 선택합니다.
  4. 안내에 따라 확인하면 계정과 데이터가 즉시 삭제됩니다.

방법 2. 이메일로 삭제 요청하기

앱을 이미 삭제하셨거나 로그인이 어려운 경우, 이메일로 요청하시면 처리해 드립니다.

계정은 유지하고 일부 데이터만 삭제하기

계정을 삭제하지 않고, 특정 취향 기록만 지울 수도 있습니다.

  1. Moodie 앱을 실행하고 로그인합니다.
  2. 하단 메뉴에서 무드보드로 이동합니다.
  3. 지우고 싶은 기록이 속한 카테고리를 선택합니다.
  4. 이미 담겨 있는 항목을 다시 한 번 누르면 그 기록이 즉시 삭제됩니다.

이렇게 삭제하면 해당 기록의 제목, 카테고리, 장르, 좋았던 점, 상황, 메모, 첨부 사진이 즉시 함께 삭제되며 별도로 보관하지 않습니다. 다만 이미 확정된 캐릭터의 진화 단계와 모습은 그 시점에 고정된 결과라 바뀌지 않습니다.

프로필의 차단 관리에서는 차단 기록을 개별적으로 해제(삭제)할 수 있습니다.

위 방법으로 처리하기 어려운 경우, 아래 방법 2와 같은 방식으로 이메일을 보내시면서 삭제를 원하는 기록을 알려주시면 확인 후 처리해 드립니다.

계정 삭제 시 삭제되는 데이터

계정을 삭제하면 아래 데이터가 모두 함께 즉시 삭제되며, 복구할 수 없습니다.

보관되는 데이터는 없습니다. Moodie는 계정 삭제 시 데이터를 별도 기간 동안 보관하지 않으며, 관련 법령에 따라 보존이 요구되는 경우에만 해당 기간 동안 보관 후 파기합니다.

참고 사항

  • 계정을 삭제해도 이미 친구에게 전송한 편지와 선물은 상대방의 받은함에 남습니다. 상대방이 받은 자신의 데이터이기 때문입니다. 다만 보낸 사람과의 연결은 끊어져, 상대방은 더 이상 회원님에게 답장할 수 없습니다.
  • 계정 삭제와 앱 삭제(제거)는 다릅니다. 앱만 지우면 계정과 데이터는 서버에 그대로 남습니다.
  • 삭제 후 같은 이메일로 다시 가입할 수 있으나, 이전 기록은 복구되지 않고 처음부터 시작합니다.
